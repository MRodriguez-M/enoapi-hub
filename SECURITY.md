# Security Policy

## Supported Versions

We actively maintain the latest version of **Eno API Hub**.

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

The security of Eno API Hub and its users is important to us. If you discover a security vulnerability, please do **NOT** open a public issue.

Instead, please send an email directly to the project maintainer:
📧 **alphrenoorz@gmail.com**

Please include:
1. Description of the vulnerability.
2. Steps to reproduce the issue (proof of concept).
3. Potential impact.

We will acknowledge receipt of your vulnerability report within 48 hours and provide a timeline for a patch.
